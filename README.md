# 皇室战争 全部塔皮图鉴

一个**离线可用的单文件网页图鉴**，收录《皇室战争》游戏内 **158 套塔皮**（Tower Skin）。
每套展示国王塔 + 公主塔（蓝方视角），全部图像由游戏内精灵文件重建渲染 —— 双击 `index.html` 即可浏览。

## 特性

| 数量 | 说明 |
| --- | --- |
| **158** | 塔皮套数，国王塔 + 公主塔双图齐全 |
| **87** | 涉及赛季（Season 1 起的赛季皮肤） |
| **154** | 可收集（Collectable） |
| **9** | 有商店上架记录（AvailableForShopOffer） |

交互功能：

- **搜索** —— 名称 / 赛季 / 资源文件名模糊匹配
- **筛选** —— 赛季下拉、`可收集`、`可上架`、`含隐藏`（默认不显示 HiddenFromClient 条目）
- **排序** —— 皮肤 Id / 按赛季分组 / 名称 A→Z
- **详情灯箱** —— 大图 + 导出名等字段，`←` `→` 翻页、`Esc` 关闭

## 快速开始

无需安装、无需联网，直接双击打开 `index.html`。

## 数据口径

`tower_skin_sets.csv` **文件共 160 行**，但其中 2 行不是皮肤：

| 行 | 内容 |
| --- | --- |
| 1 | 表头（列名 Name / SC / UseChronosId / …） |
| 1 | 类型声明行（`Name = String`，Supercell CSV 的固有格式） |
| **158** | **真实塔皮数据**（全部已渲染收录） |

158 套的构成：5 套特殊命名（`Default` / `GoldRush` / `GemRush` / `ElixerPump` / `Flood`）
+ 153 套编号命名（`TowerSkin1`–`TowerSkin88` 共 88 套，编号无缺；另 65 套为 1000+ 系列的并行版本）。
对应 154 个精灵文件（4 套共用素材）。本地所有转储版本中该表最多也是 158 条。
