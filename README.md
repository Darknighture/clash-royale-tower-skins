# 皇室战争 全部塔皮图鉴

一个**离线可用的单文件网页图鉴**，收录《皇室战争》游戏内 **158 套塔皮**（Tower Skin）。
每套展示国王塔 + 公主塔（蓝方视角），全部图像由游戏内精灵文件重建渲染 —— 双击 `index.html` 即可浏览。

## 特性

| 数量 | 说明 |
| --- | --- |
| **158** | 塔皮套数，国王塔 + 公主塔双图齐全 |
| **87** | 涉及赛季（Season 1 起的赛季皮肤） |
| **154** | 可收集（Collectable） |
| **9** | 有商店上架记录（AvailableForShopOffer） |

交互功能：

- **搜索** —— 名称 / 赛季 / 资源文件名模糊匹配
- **筛选** —— 赛季下拉、`可收集`、`可上架`、`含隐藏`（默认不显示 HiddenFromClient 条目）
- **排序** —— 皮肤 Id / 按赛季分组 / 名称 A→Z
- **详情灯箱** —— 大图 + 导出名等字段，`←` `→` 翻页、`Esc` 关闭

## 快速开始

无需安装、无需联网，直接双击打开 `index.html`。

## 目录结构

```
.
├── index.html              # 自包含单文件页面（数据内联）
└── assets/
    └── skins/              # 316 张 PNG（每套皮肤 = 国王塔 + 公主塔，240px 高）
```
